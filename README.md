# 悬浮按钮

给 Windows 远程串流和远程桌面控制用的一排悬浮快捷键。用触屏、手写笔或远程鼠标操作另一台机器时，组合键往往不方便输入；点一下悬浮按钮，就能向原本有输入焦点的窗口发送对应按键。工具本身不会抢走输入焦点。

默认提供 **退出（Esc）、后退（Backspace）、截图、复制、粘贴、语音** 六个按钮。这里的“后退”是删除前一个字符的 Backspace，不是浏览器的返回上一页。截图由工具自己完成；语音仍由你正在使用的输入法完成。

## 使用

1. 从仓库的 Releases 直接下载 `FloatingClipboard.exe` 并双击启动；Windows 压缩包则附带图标、说明和示例配置。也可以下载源码，在 Windows 上运行 `build.ps1` 自行生成 EXE；源码构建需要系统自带的 .NET Framework 和 C# 编译器。
2. 右键悬浮条或托盘图标，打开“设置”。可调整按钮大小、间距、背景透明度和显隐；点击每行右侧的快捷键框，按下想录制的按键，再点“保存设置”。截图默认使用全局 `Ctrl+Alt+Z`；若 Windows 报告该组合键已被占用，程序会清空截图快捷键，但悬浮截图按钮仍可点击。也可以点击截图快捷键框后按 `Esc` 手动清空。语音可继续使用右 Ctrl。
3. 把按钮拖到合适位置。位置和设置会保存在本机的 `shortcuts.ini`，重启后恢复。

点击截图按钮或按已启用的截图快捷键后，拖动鼠标选择任意屏幕上的区域。选区下方有画笔、直线、矩形、撤销、重选、确认和取消。选中一种绘图工具后，下方才显示线宽示例、滑动条和颜色板；确认会把截图放入剪贴板。`Esc` 取消，`Enter` 确认当前选区。

悬浮条关闭后仍在系统托盘运行；双击托盘图标可找回，右键托盘图标可退出。重复运行 EXE 也会显示已有按钮，不会启动第二份。远程控制软件需要把点击和键盘输入送到同一个 Windows 会话；若目标程序以管理员身份运行，可能需要让本工具使用相同权限。

## 配置与源码

`shortcuts.example.ini` 展示了六个按钮的默认快捷键。实际配置文件 `shortcuts.ini` 在本机保存，不会上传到仓库；推荐在设置窗口修改。`icon.svg` 是图标源文件，`icon.ico` 用于 Windows 托盘和窗口；单独运行 EXE 时会从程序内提取图标。

源码是 `FloatingClipboard.cs` 和 `ScreenshotOverlay.cs`，构建脚本是 `build.ps1`。`icons/` 中是截图绘图工具的 SVG 源图，程序内使用相同的矢量轮廓直接绘制按钮。运行 `FloatingClipboard.exe --self-test` 可检查快捷键序列、拖动边界和设置合并；自检不会发送按键或安装全局输入钩子。实际截图和语音交互需在你使用的远程串流环境中试用。
